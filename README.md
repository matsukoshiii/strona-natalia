# Natalia — strona do oceny

Otwórz **`index.html`** po rozpakowaniu całego folderu. Wszystkie zasoby są lokalne; projekt działa bez instalowania zależności lub uruchamiania serwera.

## Zawartość

- Autorskie motywy wizualne i animacje, w tym ruchome linie wokół logo i delikatne odsłanianie sekcji podczas przewijania.
- Interaktywna mapa pięciu obszarów wsparcia (również klawiaturą).
- „Brzmi znajomo?”, „O mnie”, wartości, etapy współpracy, oferta, FAQ.
- Pliki PDF do pobrania i lokalna, skrócona ankieta online.
- Responsywny układ i obsługa `prefers-reduced-motion`.

## Co jest celowo niepodłączone

Brak fikcyjnego e-maila i fałszywego „Umów wizytę”. Rezerwacje i przesyłanie danych dzieci wymagają zatwierdzonego sposobu kontaktu i odpowiednich zabezpieczeń. Formularz działa tylko w przeglądarce i nie wysyła ani nie przechowuje odpowiedzi.

Zatwierdzenia wymagają: kwalifikacje i opis usług, ceny, ewentualne zdjęcie portretowe, kontakt/rezerwacje, polityka prywatności i informacje formalne. Więcej informacji: **`START_TUTAJ.txt`**.

## Struktura

`index.html` → `style.css`, `script.js`, `assets/`, `dokumenty/`.

Zdjęcia dostarczone przez klienta zostały zoptymalizowane do WebP. Projekt nie korzysta z żadnych zewnętrznych bibliotek, CDN, formularzy innych dostawców ani analityki.
